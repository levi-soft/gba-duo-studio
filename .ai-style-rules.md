# Project conventions

## Golden Files
- `src/lib/studio/project.js`: project operations and ZIP persistence; edit cloned design state and preserve original pack files.
- `src/lib/studio/skins.js`: compile editor-only data to native layout/CSS without changing authoring data.
- `src/lib/studio/LengthInput.svelte`: bilingual visual control with explicit units.
- `src/lib/studio/generic-data.test.js`: generic data and script-preserving ZIP contracts.

## Naming & State-Control Rules
- Svelte 5 components use props and runes; pure operations live in studio JS modules.
- Keep preview and export on the same `compileDesign` pipeline.
- Main-page changes pass through `edit` for validation, undo and persistence.
- Show native authored CSS units in the Inspector; apply Thor density only for rendering.
- Keep native renderer behavior separate from authoring controls.

## DONTs
- Do not edit original template ZIPs or replace Lua and assets during visual editing.
- Do not put editor-only keys in runtime layout without compiling/removing them.
- Do not infer successful device execution from browser or automated tests.
- Do not create a separate CSS implementation for preview and export.

Scope: current studio feature work. No external hook or host configuration installed.
